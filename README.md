# DuitKita

A couples budgeting app that lets two partners track spending, set monthly
budgets, and view combined financial reports.

## Structure

- `duitkita-api/` — Go backend (Gin + GORM), deployed to Cloud Run
- `.github/workflows/` — CI/CD (Backend CI, Backend CD)

See `duitkita-api/docs/openapi.yaml` for the API spec.
